À propos

Du serveur à l'interface, sans le gap.

Étudiant en informatique à Sup de Vinci, je construis des applications web full-stack. Côté serveur : API Node.js, Next.js, authentification, persistance. Côté client : interfaces React et TypeScript.

Ma méthode : un projet réel plutôt que dix exercices. Backstage est une application que j'utilise tous les jours, déployée en production, avec une suite de tests. C'est ce cycle complet — concevoir, coder, tester, corriger, livrer — que je veux poursuivre en entreprise.

01

Livrer, pas seulement coder

Passage du code au déploiement : variables d'environnement, migrations, monitoring, rollbacks.

02

Écrire des tests

46 fichiers de tests sur Backstage. Les tests comme garde-fou, pas comme formalité.

03

Sécuriser par défaut

Passkeys, JWT courts, OAuth — et validation systématique des entrées.

Réflexions

Ce que l'IA sait,
ce qu'elle oublie.

Un modèle repart de zéro à chaque conversation. Toute la difficulté n'est pas dans la réponse — elle est dans ce qui survit d'une session à l'autre : ce qu'on garde, ce qu'on résume, ce qu'on a le droit d'oublier.

La confiance, elle, ne vient pas de la justesse. Elle vient de ce qu'on montre : d'où sort une réponse, depuis quand un souvenir existe, quand il est périmé. C'est exactement le travail sur la mémoire persistante de Backstage.

Le week-end, je photographie des concerts. Même obsession : ce que la lumière révèle, ce qu'elle laisse dans l'ombre — photo.mprnl.fr
