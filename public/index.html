Étudiant en informatique à Sup de Vinci, je construis des applications web du serveur à l'interface : API Node.js et Next.js, authentification, persistance, puis React et TypeScript côté client.

Backstage est mon terrain d'entraînement et ma vitrine : une application utilisée tous les jours, avec une suite de tests et un vrai cycle de mise en production. Concevoir, coder, tester, corriger, livrer. C'est ce cycle que je veux poursuivre en entreprise.

Ce que je livre

  • Livrer Déploiement, variables d'environnement, migrations, monitoring, retours arrière.
  • Tester 46 fichiers de tests sur Backstage, avec Vitest et Playwright.
  • Sécuriser Passkeys WebAuthn, jetons courts, OAuth, validation systématique des entrées.
